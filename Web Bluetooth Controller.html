Web Bluetooth Driverless

Koneksi instan langsung dari browser menggunakan navigator.bluetooth dan GATT, tanpa instalasi driver atau aplikasi tambahan.

Virtual Joystick & PWM

Kontrol kemudi analog dan slider kecepatan motor dengan skala PWM 0–255 untuk robot roda dua maupun empat.

Real-time Telemetri

Monitoring grafik dan sensor accelerometer, kompas magnetik, serta baterai Micro:Bit secara live.

Ultra Low Latency Mode

Optimasi paket BLE UART dengan buffer minimal untuk respons kontrol yang cepat.

Responsive Mobile UI

Tampilan ramah HP dan tablet serta mendukung gestur sentuh untuk kontrol yang lebih fleksibel.
